# В сети — гостевая страница Wi-Fi

Адаптивная страница на русском языке. Гостевой вход одной кнопкой, без SMS, пароля, номера телефона и сбора данных. Работает как статический сайт на GitHub Pages.

**Кнопка продолжает переход внутри страницы. Она не изменяет настройки роутера и не открывает доступ к интернету.** Для работы в качестве captive portal гостевую сеть необходимо настроить на роутере или контроллере отдельно.

## Локальный запуск

Нужен Node.js 22 или новее. Выполните `npm start` и откройте http://localhost:4173.

## GitHub Pages

В репозитории откройте Settings → Pages. Выберите Deploy from a branch, ветку main и папку / (root). Файлы index.html, styles.css и app.js должны находиться в корне. Относительные пути работают и для адреса вида https://username.github.io/wifi-portal/.

## Сборка

Команда `npm run build` складывает статические файлы в dist/. SMS-сервер и секретные ключи не требуются.
